# ผลงานวิชาระบบฐานข้อมูลขั้นสูง (7142202) - Aemchira (664245051)

เว็บ Streamlit รวมโปรไฟล์และการบ้านวิชาระบบฐานข้อมูลขั้นสูง (ชิ้นที่ 1-5)

```bash
pip install -r requirements.txt
streamlit run app.py
```

ไฟล์ใน `static/` (PDF, PPTX, รูปโปรไฟล์) ถูกเสิร์ฟผ่าน `enableStaticServing` ใน `.streamlit/config.toml`

Deploy: share.streamlit.io, New app, เลือก repo นี้, Main file path: `app.py`
